# CampFly

Premium experience-driven travel platform built with Next.js.

## Tech Stack
- Next.js 15
- TypeScript
- Tailwind CSS
- Framer Motion
- Sanity CMS
- Supabase
- Vercel Deployment

## Core Features
- Domestic & International Tour Packages
- Honeymoon Experiences
- Group Tours
- Dynamic Package Filtering
- WhatsApp Inquiry Conversion Flow
- SEO Blog System
- Reviews & Testimonials
- Mobile-first UI/UX
- Admin Dashboard

## Brand Direction
Travel beyond tourist spots.

Curated domestic and international travel experiences for couples, families, and explorers.

## Planned Sections

## Conversion System
Instead of direct booking, packages redirect users into WhatsApp-based conversational sales flow.
